# 보스 패턴 변경·검증

- 적용 씬: MountainPass, MountainPass_Optimized.
- 우선순위: 필요한 소환·보충 → 협동 준비 → 사용 가능한 일반 공격 중 가장 오래 안 쓴 공격.
- 첫 소환은 일반 공격 3회 완료 후. 부족한 수만 최대 생존 수까지 보충한다.
- 소환·보충 후 첫 협동을 우선하고, 완료 후에는 일반 공격 2~3회마다 다음 협동을 검토한다.
- 잡몹은 동작 중에도 예약된다. 현재 동작을 끝내고 합류하며 다음 개별 공격은 시작하지 않는다.
- 본체와 참가자가 준비되면 순간이동을 시작한다. 준비 최대 대기는 기본 10초.
- 일반 공격은 기본 연속 2회 제한. 다른 후보가 전부 불가능하면 기본 2초 대기 뒤 제한을 풀어 정지를 피한다.
- 방향 정렬은 사용 가능한 공격을 막지 않는 보조 동작이다.
- 소환 직후와 부족분 보충에도 기존 순간이동 흰 연기를 재사용한다. 초기화 완료 후 방출한다.
- 기존 체력·피해·VFX 수치 141개와 스크립트·씬 GUID를 보존했다.

## 조절 위치
천 → 게임 수치 조절 → 보스
- 일반 공격 선택 설정: 근거리 비교 기준, 연속 사용 제한, 대체 후보 대기 시간.
- 협동 공격·소환 흰 연기 설정: 협동 간 일반 공격 횟수, 참가 준비 대기, 공용 연기 수치.
- 잡몹 소환 설정: 첫 소환 공격 횟수, 소환·보충 쿨타임, 최대 생존 수.

## 검증
- 강제 패턴 호출 없는 120초 관찰: 협동 4회 시작·4회 완료, 자연 취소 0회.
- 총 점프 6회, 엎어지기 6회(협동 포함), 폭발 5회. 세 일반 공격 모두 사용.
- 일반 공격 연속 사용 최대 2회. 협동 시작 시점의 일반 공격 누적은 3, 3, 3, 2회.
- 4회 모두 행동 중인 잡몹 예약 후 진행. 최대 생존 잡몹 2마리 유지.
- 두 초기 소환 잡몹의 연기 입자와 게임 화면 확인.
- 참가자 사망 시 협동 취소·예약 해제, 생존자 유지, 부족한 한 마리 보충 및 흰 연기 확인.
- 준비 시간 초과 시 전체 예약 해제, 정렬 쿨타임 중 일반 공격 진행 확인.
- 두 씬 연결 검사 및 최종 컴파일 통과. 테스트 폴더는 비어 있다.
